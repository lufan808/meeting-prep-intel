# Quick Start

## 基本调用

```text
/portable-pre-meeting-intel Patrick Collison Stripe 评估跨境支付合作
```

也可以直接使用自然语言：

```text
准备我和北京天桥艺术中心营销负责人的会面，重点了解她最近对2027年音乐剧项目在上海市场增长的看法。
```

## 提供项目材料

如果有项目介绍 PDF、新闻稿或会议材料，可以和研究请求一起提供：

```text
结合附件中的项目介绍，准备我和项目营销负责人的会面，重点了解项目的市场定位、观众反馈和增长策略。
```

Skill 会把附件中的信息标记为“用户提供材料”或“项目方材料”，并与公开来源分开。材料中没有被公开来源验证的内容，会进入“待核实事项”，不会直接写成公开事实。

## 默认输出

输出是一份适合会前 10–15 分钟阅读的 Markdown 简报，包含：

1. 身份卡与当前叙事主线；
2. 背景与关键转折；
3. 最近信号；
4. 自述与外界叙事对照；
5. 工作方式与可直接使用的 Talking Points；
6. 可信度、来源限制和待确认事项。
